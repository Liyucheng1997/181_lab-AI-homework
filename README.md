# 作业帮 · AI 智能批改系统

一个面向老师的本地网页工具：录入班级学生名单和每次作业的标准答案，上传学生作业照片后，AI 自动识别手写答案、对照标准答案批改，在图片上生成**仿老师手写的红笔批注**（对号 ✓、叉 ✗、半对、问号、扣分、批注、总分、总评），成绩自动录入班级成绩单，并提供多维度可视化分析。

## 功能一览

| 模块 | 功能 |
|---|---|
| 班级管理 | 建班级、单个/批量导入学生名单 |
| 作业与答案 | 每次作业录入逐题标准答案与分值 |
| 智能批改 | 上传作业照片 → AI 识别与评分 → 红笔批注（可拖动微调位置、手动改判分数与批注）→ 导出批改图 PNG |
| 成绩分析 | ① 班级成绩单（可导出 CSV）② 单个学生成绩走势 + 逐题明细 ③ 单次作业逐题错误率 + 课堂讲评建议（≥40% 重点讲解） |

红笔批注做了拟真处理：每个标记带有稳定的随机抖动、笔画弧度、粗细与墨色深浅变化，批注和总分使用楷体手写字体、轻微旋转，扣分写"-n"，总分下有随手划的双下划线——视觉上接近老师用红笔批改的效果。

## 快速开始

```powershell
# 1. 安装依赖（首次）
npm install

# 2. 配置 API Key（不配置也能用「模拟批改」体验全部流程）
$env:ANTHROPIC_API_KEY = "sk-ant-..."

# 3. 启动
npm start
# 打开 http://localhost:3170
```

> 项目自带一套演示数据（五年级(2)班 + 一次已批改的作业），删除 `data/` 目录即可清空重来。

## 用哪个 AI 模型最好？

本项目通过 **Anthropic Claude API** 完成批改，核心要求是：看懂照片里的手写字（视觉识别）+ 判断答案对错（推理）+ 给出标记坐标（定位）。推荐：

| 模型 | 适用场景 |
|---|---|
| **`claude-opus-4-8`（默认，推荐）** | 视觉识别最强（支持 2576px 高分辨率图像，坐标 1:1 像素级定位），手写体辨认、等价答案判断（如 0.5 = 1/2）最可靠。批改作业首选。 |
| `claude-sonnet-5` | 质量接近 Opus、成本约为其 60%，作业量大、题目简单（客观题为主）时的高性价比选择。 |

切换模型只需设置环境变量：

```powershell
$env:GRADER_MODEL = "claude-sonnet-5"
```

每张作业一次批改约消耗 2000~5000 token（视图片大小和题量），按 Opus 4.8 价格约 ¥0.1~0.4/张。

## 技术架构

```
├── server.js          # Express 服务：班级/作业/提交 API + 静态托管
├── lib/grader.js      # AI 批改核心：Claude 视觉 API + 结构化输出（JSON Schema）
├── public/
│   ├── index.html     # 单页应用
│   ├── style.css      # 界面样式（纸张 + 墨色 + 朱红）
│   └── app.js         # 前端逻辑：红笔标注渲染引擎（SVG 显示 / Canvas 导出共用一套绘制基元）、拖拽、图表
└── data/              # 本地数据（db.json + 上传的作业图片），不上传云端
```

- 批改结果通过 **结构化输出**（`output_config.format` + JSON Schema）保证 100% 可解析；
- AI 返回每题的归一化坐标（0-1000），标记落在学生答案右侧空白处，老师可拖拽微调；
- 所有数据存在本地 `data/` 目录，学生隐私不出本机（除批改时图片发送给 Claude API）。

## 使用建议

1. **拍照质量**：作业平铺、光线均匀、字迹清晰，识别准确率最高；
2. **答案写法**：标准答案里写清等价形式（如"126平方厘米（126 cm² 也算对）"）能减少误判；
3. **人工复核**：AI 批改后建议快速过一遍批改详情，可一键改判，成绩即时更新；
4. **讲评课**：开「试卷讲评」页签，错误率排序一目了然，红色"重点讲解"的题优先讲。
